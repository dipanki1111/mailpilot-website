Outlook Search Not Working? Try These 7 Fixes

Can't find emails in Outlook? Work through these troubleshooting steps to identify common search problems.

1. Start with these quick checks

  1. Confirm that Outlook is connected to the internet and your mailbox is syncing.
  2. Search using a distinctive word from the subject or sender's email address.
  3. Check the selected search scope. Choose the appropriate current folder or all mailboxes.
  4. Look in Archive, Junk Email, Deleted Items, and other folders if an email is missing.
  5. Restart Outlook and check whether the search works again.

2. Update Outlook and Office

Install available Office updates if Outlook search started failing recently. In Outlook Classic, open File → Office Account → Update Options → Update Now, if these options are available.

Menu names may differ by Office version and organization policy.

3. Check Windows Search indexing in Outlook Classic

If Outlook Classic returns incomplete results, indexing may be incomplete or paused.

  1. Open Outlook Classic.
  2. Select File → Options → Search → Indexing Options, if available.
  3. In Indexing Options, check whether Microsoft Outlook is listed among the indexed locations.
  4. Open Outlook's search indexing status, if available, and allow indexing to finish.

Rebuilding the Windows search index can temporarily make results incomplete while indexing runs again. Use it only if simpler checks do not help.

4. Troubleshoot Outlook Classic

  • Check whether Outlook is using the expected mailbox and data file.
  • Try Outlook in Safe Mode by pressing Win + R, entering outlook.exe /safe, and pressing Enter. If search works there, an add-in may be involved.
  • Repair Microsoft 365 or Office from Windows Settings → Apps → Installed apps → Microsoft 365 → Modify, if available.
  • If only older emails are missing, review cached mail settings and whether the mailbox has finished syncing.

Before changing profiles or data files, make sure important mail is backed up and your account credentials are available.

5. Troubleshoot New Outlook

  • Check your internet connection and mailbox synchronization.
  • Remove unnecessary search filters and try a simpler search term.
  • Check Outlook on the web to see whether the same messages can be found there.
  • Install available Outlook updates. If the problem persists, use Windows app repair or reset options only after understanding their effects on local app data.

New Outlook and Outlook Classic use different search implementations, so steps for rebuilding the Windows index may not apply to New Outlook.

6. Check whether the problem affects one mailbox or all mailboxes

If search works in Outlook on the web but not in the desktop app, investigate the desktop app, its configuration, and synchronization. If the problem occurs across devices, check mailbox filters, account status, and Microsoft 365 service health where applicable.

Frequently asked questions

Why is Outlook search not showing recent emails?

Recent messages may not have synced yet, a search filter may be active, or indexing may still be in progress in Outlook Classic. Check the mailbox online and verify the search scope.

Does rebuilding the Windows index fix Outlook search?

It can help with some Outlook Classic indexing problems, but it is not a universal fix. Allow indexing to finish before judging the result.

Why does Outlook search work online but not on my computer?

This can point to a desktop application, local configuration, indexing, or synchronization issue. Compare Outlook Classic and New Outlook behavior before changing settings.

Are Outlook Classic and New Outlook search troubleshooting steps the same?

No. Some settings and indexing behavior differ, so identify which Outlook version you use before following advanced steps.
